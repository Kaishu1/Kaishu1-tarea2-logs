# Kaishu1-tarea2-logs
Repositorio para implementar la Tarea 2 de Diseño y Análisis de Algoritmos CC4102-2

## Datos de entrada

Coloca los archivos proporcionados por el equipo docente dentro de la carpeta
`datos/` del proyecto:

- `datos.bin`: obligatorio para construir los árboles y ejecutar los experimentos.
- `datos_sample.txt`: muestra opcional de los primeros 50 registros, útil para
  comprobar la lectura del archivo binario.

Estos archivos se colocan localmente y no se incluyen en el repositorio ni en la
entrega. El archivo vacío `datos/.gitkeep` permite conservar la carpeta en Git.
